# 📚 Academia de Química - Modo Educacional

## 🎯 Visão Geral

O **Modo Educacional** é uma plataforma interativa de aprendizado de química que combina teoria, exercícios resolvidos passo a passo e gamificação para proporcionar uma experiência de ensino completa e envolvente.

---

## ✨ Recursos Principais

### 🎨 Design Profissional
- **Interface moderna** com Material Design
- **Animações suaves** (fade-in, slide-in, pulse)
- **Gradientes e cores** estratégicas por dificuldade
- **Ícones intuitivos** para cada tipo de conteúdo
- **Cards elevados** com efeitos hover

### 📖 Conteúdo Didático Rico
- **12 tópicos** organizados por dificuldade (Básico, Intermediário, Avançado)
- **Múltiplos formatos** de conteúdo:
  - 📝 Textos teóricos
  - ✏️ Exercícios resolvidos passo a passo
  - 💡 Dicas e observações importantes
  - 📐 Fórmulas e equações destacadas

### 🏆 Gamificação
- **Sistema de pontos** (+10 pontos por passo concluído)
- **Streak de dias** consecutivos de estudo
- **Lições completadas** rastreadas
- **Badge de troféu** com animação de pulso
- **Barra de progresso** por lição

### 🎓 Exercícios Resolvidos
Cada exercício inclui:
1. **Problema** claramente descrito
2. **Solução passo a passo** numerada
3. **Resposta final** destacada
4. **Visual diferenciado** com cores e ícones

## 📚 Tópicos Disponíveis

### Básico
1. **🔬 Estrutura Atômica** (15 min)
   - Prótons, nêutrons, elétrons e configuração eletrônica

2. **⚖️ Balanceamento de Equações** (25 min)
   - Aprenda a balancear reações químicas com 3 exercícios resolvidos

3. **🗂️ Tabela Periódica** (15 min)
   - Propriedades periódicas e tendências

### Intermediário
4. **🔗 Ligações Químicas** (20 min)
   - Iônica, covalente, metálica e forças intermoleculares

5. **🧮 Estequiometria Aplicada** (30 min)
   - Cálculos estequiométricos com 4 exercícios resolvidos
   - Reagente limitante e rendimento

6. **🧪 Ácidos e Bases** (25 min)
   - pH, pOH, neutralização com exercícios práticos

7. **📐 Geometria Molecular** (18 min)
   - VSEPR, hibridização e polaridade molecular

8. **🧴 Soluções e Concentração** (22 min)
   - Molaridade, diluição com exercícios resolvidos

### Avançado
9. **🌡️ Termodinâmica Química** (25 min)
   - Entalpia, entropia e energia livre de Gibbs

10. **⚡ Cinética Química** (20 min)
    - Velocidade de reações e energia de ativação

11. **⚖️ Equilíbrio Químico** (30 min)
    - Kc, Kp, Le Chatelier com exercícios

12. **⚗️ Oxidorredução** (28 min)
    - NOX, balanceamento redox e células eletroquímicas

## 🎮 Como Usar

### Navegação
- **Clique** em qualquer tópico da lista à esquerda
- Use os botões **"Anterior"** e **"Próximo"** na parte inferior
- **Atalhos de teclado**:
  - `→` ou `PageDown`: Próximo passo
  - `←` ou `PageUp`: Passo anterior
  - `Home`: Reiniciar lição

### Filtros
- Filtre por dificuldade usando os **chips coloridos**:
  - 🟢 Verde: Básico
  - 🔵 Azul: Intermediário
  - 🟠 Laranja: Avançado

### Busca
- Use a **caixa de busca** para encontrar tópicos específicos

## 🚀 Exemplos de Exercícios Resolvidos

### Exemplo 1: Balanceamento
**Problema:** Balanceie: CH₄ + O₂ → CO₂ + H₂O

**Solução:**
1. Identificar os elementos: C, H, O
2. Balancear C: 1 carbono de cada lado ✓
3. Balancear H: 4H no metano → precisamos de 2H₂O
4. Balancear O: 2O no CO₂ + 2O na água = 4O → precisamos de 2O₂
5. Verificar: C(1=1) H(4=4) O(4=4) ✓

**Resposta:** CH₄ + 2O₂ → CO₂ + 2H₂O

### Exemplo 2: Estequiometria
**Problema:** Quantos gramas de água são produzidos a partir de 4g de H₂?
Reação: 2H₂ + O₂ → 2H₂O

**Solução:**
1. Massa molar: H₂ = 2 g/mol, H₂O = 18 g/mol
2. Converter H₂ em mol: n = 4g / 2g/mol = 2 mol
3. Proporção: 2mol H₂ → 2mol H₂O (razão 1:1)
4. Logo, formam-se 2 mol de H₂O
5. Converter em massa: m = 2mol × 18g/mol = 36g

**Resposta:** 36 gramas de H₂O

## 🎓 Pedagogia

### Metodologia
1. **Teoria primeiro**: Conceitos fundamentais
2. **Exemplos práticos**: Aplicação real
3. **Exercícios guiados**: Passo a passo detalhado
4. **Reforço**: Dicas e observações
5. **Resumo**: Consolidação do aprendizado

### Progressão
- Tópicos organizados do **básico ao avançado**
- **Pré-requisitos** implícitos (ex: balanceamento antes de estequiometria)
- **Tempo estimado** para planejamento de estudo
- **Feedback visual** constante (progresso, pontos)

## 🤝 Contribuindo

Para adicionar novos conteúdos:

1. **Criar método** no `EducationalViewModel` (ex: `LoadNewTopicLesson()`)
2. **Adicionar tópico** em `InitializeTopics()`
3. **Preencher conteúdo** usando os modelos:
   - `TextContent` para teoria
   - `ExerciseContent` para exercícios
   - `TipContent` para dicas
   - `FormulaContent` para equações

Exemplo:
```csharp
CurrentLessonContent.Add(new Models.ExerciseContent
{
    Problem = "Seu problema aqui",
    SolutionSteps = new List<Models.SolutionStep>
    {
        new Models.SolutionStep { StepNumber = 1, Description = "Passo 1" },
        new Models.SolutionStep { StepNumber = 2, Description = "Passo 2" }
    },
    Answer = "Resposta final"
});
```
